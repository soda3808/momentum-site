How to install a Pine Script indicator on TradingView

About 2 minutes · works on free and paid TradingView plans · no coding required

If you bought a pack of .pine source files (or received one free sample), you add them yourself in TradingView’s Pine Editor. TradingView does not “install” zip files like an app store — you paste the script once, then save it to your account.

Steps

  1. Unzip your download. Open the folder for one tool (for example 01_Smart_Session_Highlighter).
  2. Open the .pine file in any text editor and copy all of the code.
  3. In TradingView, open a chart → bottom panel → Pine Editor.
  4. Click Open → New blank indicator (or clear the default template).
  5. Paste the script → Save → name it clearly (e.g. “Kensho — Smart Session”).
  6. Click Add to chart.
  7. Optional: open the matching USER_GUIDE.md for settings and alert tips. For alerts, prefer “Once Per Bar Close”.

Common gotchas

  • Nothing on chart? Confirm you clicked “Add to chart”, not only Save.
  • Markers flicker on the live bar? Detection tools often finalise on bar close — that is normal, not a broken install.
  • Multiple tools? Repeat paste/save for each .pine file. You can stack several on one chart; start with one session tool if the chart gets noisy.
